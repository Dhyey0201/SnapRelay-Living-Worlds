# 90-second demo script

- **0–10s:** “What if a Snap could travel between friends and grow into a shared living memory?” Show the procedural Milo home scene.
- **10–25s:** Create Milo, choose a palette and open its illustrated world. Explain that the camera overlay is optional.
- **25–40s:** Choose Coffee (manual context is labeled) and Explore. Show the persisted steam glow and saved chapter.
- **40–58s:** Pass Milo to a friend and open the one-time link in a second browser/device. Preview, then accept.
- **58–73s:** Evolve Milo with Plant on Device B. Refresh A to show the same character, new holder, and read-only controls.
- **73–85s:** Open Journey and select the coffee and plant chapters to compare their actual saved 3D snapshots.
- **85–90s:** “This independent prototype explores asynchronous handoff, deterministic character evolution, and a shared server-authoritative history.”

Only claim object detection if a tested on-device detector has been added. Do not call this a published Snapchat Lens.

## Recording notes

Use your OS screen recorder at 1080p, with separate browser profiles visible when showing the handoff. Copy the invitation, then close or minimize the share dialog so the private token is not legible in the recording. Keep the manual context label visible when selecting Coffee or Plant.
